## 📖 專案簡介
這是一個專為「主婦聯盟生活消費合作社」**中壢區會**設計的數位化議事系統。本計畫旨在透過輕量化的網頁技術，優化從議程籌備到會議記錄發送的全流程效率。

在中壢區會的實驗中，我們將解決過往資訊散亂、紙本作業繁瑣的痛點，並以此作為新竹分社數位轉型的試金石。

## 🚀 核心流程設計
本系統將會議流程模組化，透過單一網址完成以下六個階段的操作：

* **議程調查期**：開放線上提案收集。
* **議程預備期**：自動彙整提案池並編號。
* **會前討論期**：委員事前針對內容提出意見，凝聚共識。
* **會議決議期**：會議當天現場進行決議錄入。
* **結論產出期**：決議通過後自動生成結論摘要。
* **紀錄發送期**：一鍵發送標準化會議記錄。

## 🛠️ 技術架構與平台
* **核心語言**：純 HTML5 / CSS3 (無框架輕量化設計)。
* **託管平台**：GitHub Pages (提供靜態網頁服務)。
* **資料中樞**：Google Sheets (透過 Google Apps Script 進行 API 介接)。
* **自動化工具**：承襲自「2026 版活動月曆填報系統」之自動化邏輯進行優化。

## 📈 版本與生命週期
* **當前版本**：`v0.1.0-alpha` (開發測試版)。
* **生命週期**：**Experimental (實驗階段)**。
    * 本計畫目前處於「中壢區會」場域測試期，視執行成效規劃推廣至分社營委會。
