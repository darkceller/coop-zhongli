# 🌿 共好議事雲 (CoopMeet) - 中壢實驗版

[cite_start]這是一個專為「有限責任台灣主婦聯盟生活消費合作社」**新竹分社中壢區會**設計的數位化議事系統。本計畫旨在透過輕量化的網頁技術，優化區會從議程籌備到會議記錄發送的全流程效率 。

## 📌 計畫緣起
[cite_start]中壢區會作為數位轉型的實驗示範區，希望透過「單一網址、流程同步」的設計，解決過往議事資訊散亂、紙本作業繁瑣以及決議追蹤不易的痛點，進而提升社務參與感並吸引青壯世代社員加入 。

## 🚀 核心流程設計 (實驗內容)
本系統將會議區分為五個主要動態階段，透過單一網址即可完成所有操作：

1. **議程調查期 (Survey)**：開放線上提案，收集委員的討論案由與辦法。
2. **議程預備期 (Collection)**：自動彙整提案池，產出正式議程表。
3. **會前討論期 (Comments)**：委員可在開會前針對提案內容預先發表意見，凝聚共識。
4. **會議進行期 (Resolutions)**：會議當天由紀錄人即時點選表決結果，紀錄討論摘要。
5. **紀錄產出期 (Distribution)**：會議結束後自動產出標準化會議紀錄，並發送通知至相關委員。

## 🛠 技術架構
為了確保系統輕量、易維護且零成本營運，採用以下架構：
* **前端網頁 (Frontend)**: 純 HTML5 / CSS3 (手刻輕量化設計)，部署於 GitHub Pages (`coop-zhongli`)。
* **資料儲存 (Database)**: Google Sheets (作為後端資料庫)。
* **系統中介 (Backend)**: Google Apps Script (GAS) 負責資料傳輸與自動化邏輯。

## 📅 實驗載體
